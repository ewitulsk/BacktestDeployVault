# BacktestDeployVault

Build a trading strategy, backtest it, deploy the same code, and let others fund its execution through a trading vault.

This repository starts with the implementation specification for the Crypto World's Fair hackathon. The specification covers the complete Hyperliquid product and its Robinhood Chain and Solana expansions. No application or contracts are implemented by this documentation change.

Start with the [specification index](docs/hackathon/README.md), [product requirements](docs/hackathon/00-product.md), and [delivery plan](docs/hackathon/11-delivery.md). Repository-wide implementation constraints are in [AGENTS.md](AGENTS.md).
